SimpleSpawn

Simple spawn plugin with customizable message prefix.
✨ Features

    Easily set a custom prefix for plugin messages via the config.yml.

    Compatible with most Minecraft versions.

    Supports Paper, Spigot, and CraftBukkit servers.

📦 Installation

    Download the standalone plugin from the Plugin folder.

    Extract and place the .jar file into your server's plugins directory.

    Important: Read and configure the config.yml file before running the plugin.
